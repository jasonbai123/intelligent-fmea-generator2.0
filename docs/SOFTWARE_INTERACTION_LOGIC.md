# 智能FMEA生成器 - 软件交互逻辑

## 1. 用户登录流程

```
┌─────────────────────────────────────────────────────────────────┐
│                        用户登录流程                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1. 用户打开应用                                                  │
│     │                                                            │
│     ▼                                                            │
│  2. 应用检查LocalStorage中的authToken                             │
│     │                                                            │
│     ├───► Token存在且未过期 → 直接进入主界面                      │
│     │                                                            │
│     └───► Token不存在或已过期 → 显示登录界面                      │
│          │                                                       │
│          ▼                                                       │
│     3. 用户输入手机号                                             │
│          │                                                       │
│          ▼                                                       │
│     4. 点击"获取验证码"按钮                                       │
│          │                                                       │
│          ▼                                                       │
│     5. 前端调用POST /api/auth/send-code                          │
│          │                                                       │
│          ▼                                                       │
│     6. 后端生成6位验证码                                         │
│          │                                                       │
│          ▼                                                       │
│     7. 后端保存验证码到KV (有效期5分钟)                           │
│          │                                                       │
│          ▼                                                       │
│     8. 后端返回验证码给前端                                      │
│          │                                                       │
│          ▼                                                       │
│     9. 前端显示验证码                                             │
│          │                                                       │
│          ▼                                                       │
│    10. 用户输入验证码                                            │
│          │                                                       │
│          ▼                                                       │
│    11. 点击"登录"按钮                                             │
│          │                                                       │
│          ▼                                                       │
│    12. 前端调用POST /api/auth/login                              │
│          │                                                       │
│          ▼                                                       │
│    13. 后端验证验证码                                             │
│          │                                                       │
│          ├───► 验证码错误 → 返回401错误                           │
│          │                                                       │
│          └───► 验证码正确 → 继续下一步                            │
│                │                                                │
│                ▼                                                │
│    14. 后端检查用户是否存在                                       │
│          │                                                       │
│          ├───► 用户不存在 → 创建新用户                           │
│          │                                                       │
│          └───► 用户存在 → 更新用户信息                           │
│                │                                                │
│                ▼                                                │
│    15. 后端生成AuthToken                                         │
│          │                                                       │
│          ▼                                                       │
│    16. 后端返回AuthToken给前端                                   │
│          │                                                       │
│          ▼                                                       │
│    17. 前端保存AuthToken到LocalStorage                           │
│          │                                                       │
│          ▼                                                       │
│    18. 前端更新应用状态                                           │
│          │                                                       │
│          ▼                                                       │
│    19. 显示主界面                                                 │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```
